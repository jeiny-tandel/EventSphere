# EventSphere – Event & Workshop Management System

EventSphere is an event and workshop management system designed to streamline the planning, organization, and participant handling for events and workshops.

## Purpose

The purpose of EventSphere is to provide a unified platform for organizers to create, manage, and coordinate events and workshops, while enabling attendees to register, receive real-time updates, and engage effectively.

## Planned Technology Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Ant Design, Redux Toolkit
- **Backend:** NestJS
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Authentication:** JWT
- **API Communication:** Axios
- **Real-time Communication:** Socket.IO
- **Containerization:** Docker and Docker Compose
